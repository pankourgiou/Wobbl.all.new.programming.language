Wobbl

A language that knows nothing is ever quite exact.

Wobbl gives values room to move: numbers written with their own tolerance, comparisons that can be approximate on purpose, and a syntax built for pattern matching and pipelines instead of nested branches. People who write it call themselves wonks.

Try it live Read the syntax tour
radius — nominal 12.0, tolerance ± 0.3
let radius ~= 12.0 +/- 0.3

Why wobble

A sensor reads 9.8 m/s² today and 9.81 tomorrow. A recipe calls for "a cup, more or less." A user types a price as $19.99 or just $20. Most languages force you to collapse all of that into one exact number and quietly forget the rest.

Wobbl keeps the rest. You write down how sure you are, right alongside the value, and the language carries that uncertainty through your arithmetic, your comparisons, and your branching — instead of making you build it yourself out of tuples and hope.

It's still a small, opinionated, functional-leaning language underneath: immutable by default, first-class functions, pattern matching over deep if-chains, and a pipeline operator for code that reads left to right. The wobble is the headline feature, not the whole language.

A tour, in five moves

Every language demo starts with hello world. This one ends somewhere a little stranger.

Say what you mean

No main(), no boilerplate. A file is a script; say writes to the console, let binds a name that can't be reassigned.

let → immutable by default 
# hello.wob
let name = "Ada"
say "Hello, {name}!"
# => Hello, Ada!

Give it room to move

The ~= operator declares a wobbly value with a nominal amount and a tolerance. Arithmetic on wobbly values propagates the uncertainty automatically.

+/- → tolerance, carried through math 
# a wobbly value: nominal 12.0, tolerance ±0.3
let radius ~= 12.0 +/- 0.3

jig area(r) => 3.14159 * r * r

say "Area is {area(radius)}"
# => Area is 452.4 ± 22.6

let exact = settle(radius, using: nearest)
# => 12.0 — collapses the wobble when you need one number

Ask, don't branch

when replaces long if/else chains. The ~= operator works here too — is ~= 20 +/- 2 matches anything close enough, not just equal.

is ~= → fuzzy match, not exact 
jig describe(temp) => when temp {
  is < 0          => "freezing"
  is ~= 20 +/- 2  => "room temperature"
  is > 35         => "scorching"
  else            => "somewhere in between"
}

say describe(21.4)  # => room temperature

Read code like a sentence

The pipeline operator |> threads a value through a chain of calls, left to right, instead of nesting them inside out.

|> → pipe result into next call 
let total = [4, 8, 15, 16, 23, 42]
  |> filter(x => x > 10)
  |> map(x => x * 2)
  |> reduce(0, (sum, x) => sum + x)

say total  # => 192

Functions that remember

jig declares a function — closures capture their surrounding scope like you'd expect, and mut opts a single binding into mutability when you actually need it.

mut → the deliberate exception to let 
jig make_counter() {
  mut count = 0
  return () => {
    count = count + 1
    count
  }
}

let tick = make_counter()
say tick()  # => 1
say tick()  # => 2

Get started

      
Here's the honest version of what that would look like.

    

    
Wobbl source files use the .wob extension — hello.wob, main.wob, and so on. One language, one extension; no .wobx or .wbl variants to keep straight.

    

      
      
$ wob new orchard

      
  creating orchard/main.wob …

      
$ cd orchard && wob run

      
Hello, World!

      
$ # there's no compiler behind this yet — see below

    

    
Wobbl is a concept language — a syntax sketch, not a shipped compiler. Everything on this page runs in nobody's terminal but this thought experiment. If you like the idea of values that carry their own uncertainty, steal it, build it, or tell a wonk it's a terrible idea. Either reaction means it did its job.
